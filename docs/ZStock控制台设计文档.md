## 1. 工作台

**功能**：打开即见今日状态，快速跳到研究 / 运维 / 交易。

**显示**
- 时间线：最近夜跑、最近回测、未完成任务
- 摘要数字：进行中任务数、订单数
- 行情条：大盘行情、国际金价
- 资讯区：AI 汇总的最新信息（只读摘要，可点开原文若有）

**操作**
- 从时间线进入：回测结果 / 任务与夜跑
- 快捷入口：因子库 · 策略库 · 数据管理 · 订单

---

## 2. 研究

研究下分：**因子库**（编排）→ **策略库**（沉淀）→ **详情 / 回测**（验证）。

### 2.1 因子库

**功能**：选因子、调权重与极性，命名后保存为策略；可选保存并直接开回测。可从策略详情带入已有组合继续改。

**显示**
- 层切换：板块 / 龙头 / 合力
- 体制切换：动量 / 反转
- 因子列表：中文名、勾选、权重、极性（正向 / 反向）
- 已选摘要：按层汇总；缺层提示
- 策略名、说明、回测区间

**操作**
- 编辑因子组合
- 保存到策略库 → 策略详情
- 保存并回测 → 回测结果
- 链到策略库

### 2.2 策略库

**功能**：浏览已保存策略。

**显示**：名称、说明、更新时间、因子数量

**操作**：点进详情；链到因子库新建

### 2.2.1 策略详情

**功能**：读懂因子组合；继续编辑、发起回测、看历史回测。

**显示**
- 策略名、说明
- 因子可读摘要（中文名 · 权重 · 正向 / 反向）
- 历史回测：状态、区间、收益、时间

**操作**
- 继续编辑 → 因子库（带入当前组合）
- 发起回测 → 回测结果
- 点历史记录 → 对应回测结果
- 回策略库

### 2.2.2 回测结果

**功能**：看单次回测状态与绩效；运行中自动刷新。

**显示**
- 状态与错误信息
- 累计收益、年化、最大回撤、夏普、区间
- 全宽净值曲线

**操作**：回策略详情；去因子库（本页不提供「再跑一次」）

## 3. 运维

### 3A. 数据源管理

**功能**：查看并测试三类外部数据源是否连通；不写库、不改配置、不触发同步。

| 数据源 | 用途 |
|--------|------|
| akshare | 东财等补充行情 / 板块 / 交易状态 |
| QMT 桥 | 本机交易与实时行情桥 |
| stockdb | 日线 / 资金流主源 |

Mongo 连通性放在「数据管理」页顶，不与这三源并列。

**显示（每源一行）**
- 名称、状态（未知 / 正常 / 异常 / 未配置）
- 端点摘要（host、路径等只读；**不展示 Token**）
- 最近探测：时间、耗时、结果摘要

**探测成功**
- akshare：能加载并拉到样本
- QMT 桥：能 ping 通（缺 Token → 未配置）
- stockdb：能连上并读到极少样本（SDK 缺失 → 未配置）

**操作**：刷新状态 · 全部探测 · 每行测试连接

### 3B. 数据管理

**功能**：只读浏览 Mongo——列出全部集合，按条件查文档并可翻页看完。  
禁止增删改、删集合、建索引、触发同步（同步在「任务与夜跑」）。

**显示**
- 页顶：当前库连接状态（可测 Mongo）
- 集合目录：名称、文档数、最新交易日（无则 —）
- 文档区：筛选（代码、日期起止；高级条件默认折叠）、结果表、本页 / 总条数估计

**操作**：测试 Mongo · 刷新集合 · 选集合 · 查询 · 翻页 ·（可选）复制一行 JSON

> 「查全库」= 任意集合都能查、可翻页穷尽；禁止一次无分页拉光大表。

### 3C. 任务与夜跑

**功能**：管 Python 进程内夜跑调度（stockdb → Mongo → 因子）；触发同步；看异步任务。无需 Windows 计划任务。

**显示**：夜跑是否注册、状态、下次 / 上次运行；任务列表（类型、状态、消息、时间）

**操作**
- 立即跑夜跑 · 启用 · 禁用 · 刷新
- 同步日线 · 同步资金流 · 预计算因子 · 跑完整夜跑流水线

---

## 4. 交易

**功能**：只读看委托 / 成交，不下单、不改单。

**显示**：订单号、代码、方向、数量、状态、环境、时间；空态「暂无成交/委托」

**操作**：按代码 / 状态 / 环境筛选后查询

---

## 5. 主路径

```
工作台 → 因子库编排 → 存策略 → 回测看净值
工作台 → 行情 / AI 资讯只读浏览
运维 → 测数据源 → 数据管理查库 → 任务与夜跑同步
交易 → 查订单
```
