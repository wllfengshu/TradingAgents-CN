# 参数网格搜索使用指南

## 概述

参数网格搜索是在给定参数空间中，自动遍历所有参数组合，对每个组合进行回测，找出最优配置的过程。

```
参数空间 (1000+ 组合)
    ↓
采样 (100 组合)
    ↓
对每个组合执行回测
    ↓
计算性能指标
    ↓
排序选出最优配置
    ↓
导出结果报告
```

## 参数搜索空间详解

### 1. 布林上升滤 (M0.5)

```python
'bollinger_slope_threshold': [0.0, 0.002, 0.005]
```

| 值 | 含义 | 影响 |
|----|------|------|
| **0.0** | 严格：中轨必须向上 | 选的票少，质量高 |
| **0.002** | 中等：中轨向上或微负 | 平衡 |
| **0.005** | 宽松：中轨变化不大 | 选的票多，质量低 |

**建议：** 先试 0.0（严格），不够再松

---

### 2. 板块选择 (M1)

```python
'top_sectors': [2, 3, 5]
```

| 值 | 含义 | 风险 |
|----|------|------|
| **2** | 保守：只看top2板块 | 集中度高 |
| **3** | 标准：看top3板块 | 平衡 |
| **5** | 激进：看top5板块 | 分散，可能混入弱板块 |

**建议：** 3（标准）

---

### 3. 龙头选择 (M2)

```python
'top_per_sector': [2, 3, 5]
```

每个板块选几只龙头

| 值 | 含义 | 收益 | 风险 |
|----|------|------|------|
| **2** | 保守 | 低 | 低 |
| **3** | 标准 | 中 | 中 |

**建议：** 2-3（不要太多）

---

### 4. 合力验证 (M3)

```python
'cooperative_force_scheme': ['A', 'B']
'cooperative_force_threshold': [0.10, 0.15, 0.20]
```

**方案对比：**

| 方案 | 规则 | 通过率 | 质量 |
|-----|------|--------|------|
| **A** | 主力>0 & 散户≥0 | 高(70%) | 中 |
| **B** | 占比>X% | 低(30%) | 高 |

**建议：** B + 0.15（严格但准确）

---

### 5. 最终权重 (M4)

```python
'weight_sector': [0.3, 0.4, 0.5]      # 板块权重
'weight_dragon': [0.3, 0.35, 0.4]     # 龙头权重
# 合力权重 = 1 - sector - dragon
```

**例子：**

| sector | dragon | coop | 含义 |
|--------|--------|------|------|
| 0.4 | 0.35 | 0.25 | **标准（推荐）** |
| 0.5 | 0.3 | 0.2 | 板块优先 |
| 0.3 | 0.4 | 0.3 | 龙头优先 |

**建议：** 0.4/0.35/0.25（标准）

---

### 6. 最终选择 (M4)

```python
'top_k': [3, 5, 10]
```

| 值 | 含义 |
|----|------|
| **3** | 保守：只要最好的 |
| **5** | 标准 |
| **10** | 激进：很激进 |

**建议：** 5（标准）

## 搜索过程

### Step 1: 定义参数空间

已在代码中定义，包含 3×3×2×2×3×3×3×3 = **648 种组合**

### Step 2: 采样

648 太多，采样 50-100 组合进行搜索

```python
# 快速演示
python grid_search.py --max-combinations 50   # 50个组合，2秒完成

# 完整搜索
python grid_search.py --max-combinations 200  # 200个组合，5秒完成
```

### Step 3: 对每个组合执行回测

```
配置文件 (strategy_params.json)
    ↓ 更新参数
组合1: top_k=3, weight_sector=0.4, ...
    ↓ 运行策略
获得100条信号
    ↓ 计算性能
得分 = 信号数量 × 平均得分
```

### Step 4: 排序并输出最优配置

```
组合1: 得分=0.85
组合2: 得分=0.83
组合3: 得分=0.81
...
```

## 结果解读

### CSV 输出

```
combination_id,top_sectors,top_k,weight_sector,weight_dragon,...,num_signals,avg_score,signal_quality,status
1,2,3,0.3,0.3,...,5,75.4,3.77,success

3,3,3,0.4,0.35,...,7,78.9,5.52,success
```

### 关键指标

| 指标 | 含义 | 好坏判断 |
|-----|------|--------|
| **signal_quality** | 信号质量得分 | 越高越好 |
| **num_signals** | 生成的信号数 | 通常5-20只 |
| **avg_score** | 平均得分 | 通常70-85 |
| **status** | 执行状态 | success/failed |

## 常见问题

### Q: 搜索多久完成？

**A:** 
- 快速演示版：50组合 = 2秒
- 真实版：20组合 = 5-10分钟（取决于数据量）

### Q: 如何扩大搜索范围？

**A:** 在 `get_parameter_space()` 中添加更多参数值：

```python
'top_k': [2, 3, 5, 7, 10],  # 从3个增加到5个
```

### Q: 怎样选参数搜索集合？

**A:** 
1. **保守**：用标准参数周围搜索
2. **全面**：用 `get_parameter_space()` 中的全量参数
3. **激进**：参数范围更大

### Q: 搜索完后怎么用最优参数？

**A:** 
```python
# 更新 config/strategy_params.json
{
  "final_score": {
    "weights": {
      "sector": 0.4,      # ← 从搜索结果复制
      "dragon": 0.35,
      "cooperative": 0.25
    },
    "top_k": 5             # ← 从搜索结果复制
  }
}
```

然后重启策略，使用新参数。
