# 量化交易系统架构设计

名称：智股-Zstock
代码路径：/zstock

## 一、系统分层架构

```
┌─────────────────────────────────────────────────────────────┐
│                    第 0 层：治理与监控层                       │
│              Monitor Management                       │
│              (AI Agent 智能中枢 + 性能监控)                      │
│   [实时监控] [诊断归因] [报告生成] [预警] [代码审查]            │
└─────────────────────────────────────────────────────────────┘
                            ↓ 监督并反馈
┌─────────────────────────────────────────────────────────────┐
│                    第 1 层：数据层                            │
│         Data Management                     │
│         (AKShare + XtQuant + Redis + MongoDB)               │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                    第 2 层：研究层                            │
│            Factor Management              │
│              (Qlib+Factor)                   │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                    第 3 层：策略层                            │
 │             Strategy Management                       │
│           Portfolio Construction & Risk Control              │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                    第 4 层：执行层                            │
│              Order Management                               │
│                    (XtQuant API)                            │
└─────────────────────────────────────────────────────────────┘
                            ↑ 反馈
                    第 0 层（闭环）
```
