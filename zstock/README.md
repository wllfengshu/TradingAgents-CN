## 一、系统分层架构

```
┌─────────────────────────────────────────────────────────────┐
│                    第 0 层：治理与监控层                       │
│              Monitor Management                       │
│              (AI Agent 智能中枢 + 性能监控)                      │
│   [实时监控] [诊断归因] [报告生成] [预警] [代码审查]            │
└─────────────────────────────────────────────────────────────┘
                            ↓ 监督并反馈
┌─────────────────────────────────────────────────────────────┐
│                    第 1 层：数据层                            │
│         Data Management                     │
│         (AKShare + XtQuant + Redis + MongoDB)               │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                    第 2 层：研究层                            │
│            Factor Management              │
│              (Qlib+Factor)                   │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                    第 3 层：策略层                            │
 │             Strategy Management                       │
│           Portfolio Construction & Risk Control              │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                    第 4 层：执行层                            │
│              Order Management                               │
│                    (XtQuant API)                            │
└─────────────────────────────────────────────────────────────┘
                            ↑ 反馈
                    第 0 层（闭环）
```


红黄绿就是进攻、中性、防守。三个策略每天都跑，灯决定仓位落在哪一层。

灯看沪深300收盘离 120 日均线有多远。高于均线 3% 才亮绿灯，低于均线 3% 才亮红灯。绿灯和红灯都要等收盘回到均线才灭，避免贴着 3% 来回跳。中间是黄灯。

**绿灯，进攻。** 新买先用截面要的股票，权重没用完再用行业 ETF 要的品种，还没用完用低波补上。三层都可以新开。

**黄灯，中性。** 不再买新股票。手里的股票里，截面还要的留下，不要的卖掉。腾出来的权重买行业 ETF。行业 ETF 没占满的部分用低波补上：30 年国债 35%，10 年国债 35%，其余 30% 先黄金，再银行，否则政金债。

**红灯，防守。** 股票一律卖掉，不管截面还要不要。手里的行业 ETF，行业策略还要的留下，不要的卖掉，不再买新的行业 ETF。腾出来的权重买低波：30 年国债 35%，10 年国债 35%，其余 30% 先黄金，再银行，否则政金债。
