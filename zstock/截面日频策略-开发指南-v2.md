# 📘 「主线 → 龙头 → 合力」截面日频策略 · 开发指南 v2

> **版本**：v2.0.0（2026-08-07）  
> **适用**：国金 miniQMT / A 股主板-only / T 收盘决策 → T+1 开盘执行  
> **前置文档**：[截面日频策略-开发指南.md](./截面日频策略-开发指南.md)（v1，部分权重/因子已过时）  
> **代码现状**：P0 已落地（M3/M4 角色分离 + M5 权重 0.25/0.35/0.40）；本文档为 **P1/P2 目标规格**

---

## 零、本文档解决什么问题

v1 指南与当前代码存在三处脱节：

1. **交易节拍**：策略物种是日频，但 M4 仍 heavily 依赖 L2 日终汇总，缺少「龙虎榜」这类日频可审计的合力确认。
2. **因子角色**：弱 IC 因子与强 filter 因子混在加权打分里（测评已证实 f31/fcoop1 OOS 失效）。
3. **数据源边界**：**北向、融资暂不纳入**；**龙虎榜走 QMT 本地环境**，与现有 `xtquant_data_utils` / MongoDB 缓存体系对齐。

v2 把「盘中时序捕捉」彻底替换为 **T 日及以前可获取的日频替代指标**，并明确 α / φ / 加分 三类角色。

## 一、策略定位（物种锁定）

| 维度 | 设定 |
|------|------|
| 市场 | A 股主板：沪 `60/601/602/603/605`、深 `000/001/002/003`；剔除创业/科创/北交/ST |
| 频率 | **日频截面**：T 日收盘后算分 → T+1 日开盘（集合竞价或开盘价）调仓 |
| 持股 | 通常 1–5 个交易日；按信号强弱 + 退出规则动态调整 |
| 物种 | 主线板块里的**趋势中军/龙头**，日频轮换。**非打板、非抄底、非震荡市策略** |
| 空仓 | 无主线日 / M1 红灯 / 全市场极端风险 → 不开新仓；旧仓按退出规则管理 |

### 1.1 日频交易节拍（强制）

```
T 日 15:00   收盘
T 日 15:30   OHLCV、涨停/连板、L2 日终汇总 可算
T 日 17:00+  龙虎榜数据可获取（QMT get_longhubang）
T 日 17:30   跑 pipeline → 产出 T+1 目标持仓
T+1 日 09:25 集合竞价 / 09:30 开盘价执行
```

> **禁止**在 T 日决策中使用 T+1 才能拿到的数据。  
> **北向、融资**：v2 **明确不纳入**（后续版本再评估）。

```
│  M4  ForceFactors       合力确认（L2 φ + 龙虎榜加分 + fcoop4 α）   │

└─────────────────────────────────────────────────────────────────┘
```

### 2.1 因子角色约定（全篇统一）

| 角色 | 符号 | 含义 | 用法 |
|------|------|------|------|
| 排序 α | **α** | 截面 Rank IC 稳定为正，或业务上明确「比谁更强」 | 进 min-max 加权打分 |
| 硬门槛 | **φ** | 事件/布尔/区间约束，过/不过 | 不进加权；不过则剔除 |
| 加分 | **+** | 稀疏事件（龙虎榜、分歧转一致） | 固定加分或满足 N/M 规则；缺失不惩罚 |

### 3.2 QMT 龙虎榜接口

迅投官方接口（[龙虎榜文档](http://docs.thinktrader.net/pages/1b01b0/)）：

```python
# 大 QMT 内置 Python（ContextInfo）
C.get_longhubang(stock_list, startTime, endTime)
# 返回 DataFrame：reason, close, spreadRate, Turnover_Amount,
#                 buyTraderBooth, sellTraderBooth（含 traderName, buyAmount, sellAmount, rank...）
```

**外部 Python（MiniQMT + xtquant）推荐路径**：

1. **方案 A（推荐）**：在 MiniQMT 内置策略环境跑 `sync_lhb` 定时任务，写入 MongoDB；主 pipeline 只读 MongoDB（与 OHLCV 同步模式一致）。
2. **方案 B**：外部 Python 通过 QMT RPC / `call_method` 桥接（若本地已配置）；封装进 `zstock/common/utils/xtquant_data_utils.py` 的 `fetch_lhb()`。

> 工程约束：**pipeline 不直接调 QMT**，统一 `query_service.get_lhb()` → MongoDB 缓存 → 因子层。  
> 回测使用 MongoDB 历史龙虎榜；无龙虎榜日视为「该因子缺失」，**不扣分**。

### 3.3 龙虎榜 MongoDB 文档 Schema（建议）

```python
{
    "code": "600000",           # 6 位
    "trade_date": "2026-08-06",
    "reason": "涨幅偏离值达7%...",
    "close": 10.5,
    "spread_rate": 0.099,
    "turnover_amount": 1.2e9,
    "buy_booths": [             # 买方 TOP5
        {"trader_name": "...", "buy_amount": 1e8, "buy_pct": 0.12, "rank": 1},
        ...
    ],
    "sell_booths": [...],
    "inst_buy_amount": 0.0,     # 预聚合：机构买入总额
    "inst_buy_ratio": 0.0,      # 机构买入 / 总买入
    "top1_buy_ratio": 0.0,      # 买一席位占比（游资分散度）
    "net_buy_amount": 0.0,      # 买卖净额（若可算）
    "source": "xtquant",
}
```

索引：`{code: 1, trade_date: -1}`；`{trade_date: 1}`。

### 3.4 load_real_data 扩展（目标 10 字段）

在 v1 九字段基础上增加：

```python
'stock_lhb_recent': Dict[str, List[Dict]]  # {code: [近 N 日龙虎榜 doc，末条=trade_date]}
```

`run_pipeline` / `score_signals` 预计算路径同步扩展该字段（可为空 dict，M4 降级为纯 L2）。

## 四、M1 环境层（MarketFactors）

**职责**：管「做不做、做多少」，不管「买谁」。

### 4.1 现有因子（保留）

| 因子 | 权重 | 说明 |
|------|------|------|
| MF1 趋势强度 | 30% | 沪深300 的 20MA 斜率 |
| MF2 布林位置 | 25% | 指数 close 在布林带中的位置 |
| MF3 量能状态 | 20% | 当日量 / 20 日均量 |
| MF4 近期动量 | 15% | 5 日涨跌幅 |
| MF5 波动率压制 | 10% | ATR/MA，低波动高分 |

### 4.2 v2 新增环境 φ（P2）

| 因子 | 规则 | 说明 |
|------|------|------|
| MF6 全市场跌停数 | T 日跌停家数 > 50 → 禁止开新 | 系统性风险 |
| MF7 指数 MA20 | 上证/沪深300 close < MA20 → 黄/红灯加权 | 大盘趋势过滤 |
| MF8 主线分化度 | 全板块 RPS 截面 std < 阈值 → 无主线日 | 对接 `no_mainline.rps_std_threshold` |

**输出**：

| grade | score | position_scale | 动作 |
|-------|-------|----------------|------|
| green | ≥70 | 1.0 | 正常开仓 |
| yellow | 40–70 | 0.4（代码现状） | 缩仓 |
| red | <40 | 0.0 | 禁止开新；配合退出规则减仓/清仓 |

## 五、M2 主线层（SectorFactors）

**职责**：回答「今天有没有主线？是哪几条？」

**输出**：Top **1–3** 板块（v2 目标；当前代码 Top 5，P1 调参验证）。

### 5.1 因子清单

| 因子 | 角色 | 日频计算 | 权重/规则 | 现状 |
|------|------|----------|-----------|------|
| F2.1 动量 RPS | α | 板块 5/10/20 日累计收益 → 截面 rank；**P1 改为 RPS 加速度** | 25% | 有 F2.1（仅 20d） |
| F2.2 板块净流入 | α | 主板成分 T 日 main_net 求和 | 15% | 有 |
| F2.3 涨停密度 | φ | 涨停家数 / 主板成分数；**>0 才进候选** | φ | 有 |
| F2.4 连板高度 | φ | 板块内最高连板数；**≥1 加分** | + | 有 |
| F2.5 成交额占比 | α | 板块成交额 / 全市场成交额 | 10% | 间接（斜率） |
| **F2.6 成交额 5 日增量** | **α** | `MA5(amount_share) / MA20(amount_share) - 1` | **25%** | **待建** |
| **F2.7 60 日新高率** | **α** | 成分股创 60 日新高占比 | **15%** | **待建** |
| **F2.8 10 日持续性** | **φ** | 近 10 日板块涨幅排全市场前 10% 的天数 ≥ 3 | **φ** | **待建** |

### 5.2 合成逻辑（v2 目标）

```
Step1  φ：F2.3>0 且 F2.8≥3 且 非黑名单板块
Step2  α：F2.6 + F2.1b(RPS加速度) + F2.7 + F2.2 + F2.5 → MainlineScore
Step3  取 Top 1–3；并列时 F2.6 优先
```

### 5.3 测评备注

2025/2026 测评：M2 五因子 Rank IC 均 ≈0，f21 RPS 2025 转负。  
**结论**：M2 不应再堆弱 α；**持续性 φ + 成交额增量 α** 是 v2 改造重点。

## 六、M3 龙头层（DragonFactors）

**职责**：在主线板块内回答「谁是龙头/中军？」

**输出**：每板块 Top **1–2** 只（v2 目标；当前 top_per_sector=4）。

### 6.1 P0 已实现（代码现状）

| 因子 | 角色 | 说明 |
|------|------|------|
| f32 成交额 | **α 55%** | 取反（反拥挤）；OOS Rank IC 最强 |
| f34 量价共振 | **α 45%** | 取反；双年 Rank IC 为正 |
| f33 连板 | **φ** | 连板≥1 **或** f35_bollinger_pass=1 |
| f35 布林趋势 | **φ** | 趋势分 ≥ 40 |
| ~~f31 超额 5d~~ | **移除** | 双年 Rank IC 负 |

### 6.2 v2 待增因子

| 因子 | 角色 | 日频计算 | 说明 |
|------|------|----------|------|
| **F3.1b 板块内 RPS 分位** | **α** | 个股 20 日收益在板块内 percentile | 替代 f31 5 日超额 |
| F3.0 收盘封板 | **φ/+** | T 日涨停收盘 = 1 | 替代「盘中涨停时序」 |
| F3.6 自由流通市值 | **φ** | QMT FloatVolume；过滤过大/过小 | 中军规模 |
| F3.7 上方阻力 | **φ** | `(HHV250 - close) / close` 越小越好 | 筹码结构 |
| F3.8 换手健康度 | **φ** | T 日换手 5%–35%，且 ≥ 近 20 日 60% 分位 | 活跃不极端 |
| F3.9 放量启动 | **+** | 量 > 1.5×MA20 且收阳 | 事件加分 |
| F3.10 分歧转一致 | **+** | T-1 长上影/阴线 + T 反包涨停放量 | 事件加分 |
| F3.11 近 3 日波动率 | **α 备选** | 3 日收益 std 越小越好 | 替代盘中人气 |

### 6.3 v2 目标合成

```
φ：f35≥40 AND (f33≥1 OR boll_pass) AND 市值区间 AND 换手健康
+：分歧转一致 / 放量启动 / 收盘封板（有则加分，无则不罚）
α：0.4×RPS分位 + 0.35×f32反 + 0.25×f34反（板块内 min-max）
```

## 七、M4 合力层（ForceFactors）

**职责**：回答「有没有真实资金在推？推的质量如何？」

v2 采用 **「L2 硬门槛 + 龙虎榜加分 + fcoop4 α」**，不用北向/融资。

### 7.1 P0 已实现（代码现状）

**φ 硬门槛（必须全部满足）**：

```
main_net > 0
main_net / turnover >= 5%（strategy_params cooperative_force.threshold_pct）
近 5 日 main_net > 0 的天数 >= 2
```

**α 打分**：仅 **fcoop4 换手质量**（取反后 min-max，权重 100%）。

**已移除**：fcoop1/fcoop2 的 α 权重（fcoop1 保留在 φ；fcoop2 删除）。

### 7.2 v2 龙虎榜因子（QMT 源）

| 因子 | 角色 | 计算 | 规则 |
|------|------|------|------|
| **LHB1 机构买入占比** | **+** | 机构买入额 / 龙虎榜总买入额 | 有龙虎榜且 >30% → +10 分 |
| **LHB2 游资分散度** | **+** | 买一席位买入 / 总买入 | <30% → +8 分（避免独食） |
| **LHB3 净买额强度** | **+** | 净买额 / 当日成交额 | 归一化加分 |
| LHB0 是否上榜 | **+** | T 日是否在龙虎榜 | 上榜 +5；**未上榜不扣分** |

**合力判定（v2 目标）**：

```
Step1  L2 φ 全过（P0 三道门槛）
Step2  coop_score = fcoop4_norm + lhb_bonus（上限 cap=100）
Step3  进入 M5 合成
```

> 稀疏数据原则：**龙虎榜是加分，不是必要条件**。  
> 测评未覆盖 LHB 因子，P1 落地后须补 2025/2026 因子测评。

### 7.3 量价配合（与 f34 分工）

| 层 | 因子 | 语义 |
|----|------|------|
| M3 | f34 共振 | 个股近 5 日量价健康 **天数占比** |
| M4 | **F4.5 阳量/阴量比** | 近 10 日阳线均量 / 阴线均量 > 1.2（**φ 或 +**） |

避免 f34 与 F4.5 重复加权；v2 建议 F4.5 作 M4 的 φ（不过则剔除）。

## 八、M5 + M6 合成与选股

### 8.1 权重（P0 已写入 strategy_params.json v1.3.0）

```
final_score = (0.25 × sector_rank + 0.35 × dragon_score + 0.40 × coop_score) / 1.0
```

设计理由（结合测评）：

- M2 无稳定 IC → 降权至 0.25（板块已是 Top-K 漏斗）
- M3 龙头是核心 α → 0.35
- M4 fcoop4 OOS 最稳 + 龙虎榜加分 → 0.40

### 8.2 M6 输出

- `top_k = 5`（可调）
- 宽宇宙 `max(top_k×4, 20)` 供**排名退出**（strategy 层）
- 每条信号携带 `market_grade`、`position_scale`

## 九、策略层：执行与退出

### 9.1 买入（T+1 开盘）

- 对 M6 最终池按 `final_score` 降序
- 单票上限 **15%**（`portfolio.max_weight_per_stock`）
- 行业暴露上限 **40%**
- 黄灯 `position_scale=0.4` 缩仓（不归一化回 1.0，留现金）

### 9.2 卖出 / 持仓管理（v2 完整规则）

| 规则 | 触发 | 优先级 | 代码现状 |
|------|------|--------|----------|
| 硬止损 | 相对入场价 ≤ -6% | 最高 | ✅ |
| 排名退出 | 截面 rank 分位 > 80% | 高 | ✅ |
| 跌出候选 | 连续 2 日不在 buy 名单 | 高 | ✅ |
| 坏环境清仓 | 连续 3 日 red/无信号 | 高 | ✅ |
| **主线掉出 Top3** | 所属板块不在 M2 Top3 | 中 | **待建**（现 Top5） |
| **连板中断** | 持仓股连板天数归零且未涨停收盘 | 中 | **待建** |
| **放量滞涨** | T 日收阴且量 > 1.3×MA20 | 中 | **待建** |
| Buffer + 最短持有 | 8 日；force_exit 豁免 | 低 | ✅ |

### 9.3 空仓条件

- M1 red
- `no_mainline`：板块 RPS 分化 < 阈值（**待接线**）
- 全市场跌停 > 50（**待建**）

## 十三、因子验收标准

每个新因子上线前必须：

1. **时点**：仅使用 T 日及以前数据（龙虎榜 ≥17:00 跑 pipeline）
2. **测评**：`run_eval.py` 在 **2025（OOS）+ 2026（IS）** 双区间出 Rank IC
3. **角色**：
   - Rank IC 双年正 → 候选 **α**
   - 稀疏/事件型 → **+** 或 **φ**
   - OOS 转负 → 不得进 α
4. **回测**：与 P0 baseline 比 收益/MDD/夏普/换手；OOS 优先
