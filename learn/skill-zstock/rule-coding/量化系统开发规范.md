**高内聚设计、因子封装、入参精简、分层架构**，

量化因子计算框架，它遵循以下原则：

- **每个因子完全封装在自己的类中**：所有与该因子相关的逻辑（校验、计算、边界处理）都在一个类里完成，不散落在外。
- **入参极简**：因子构造函数只接收必要参数（如窗口大小、权重等）；`calculate` 方法只接收一个统一的数据容器（如 `MarketData` 对象），避免大量零散参数。
- **分层清晰**：数据校验层、因子计算层、因子组合层各司其职，互不越界。
- **严谨报错**：任何数据异常（缺失、格式错误、长度不足）都抛出明确异常，绝不静默兜底。

---

### 架构总览（示例）

```
┌─────────────────┐
│   MarketData    │  数据层：统一封装原始行情，提供安全访问
├─────────────────┤
│  DataValidator  │  校验层：全局数据校验，确保传入因子前的数据干净
├─────────────────┤
│  FactorBase     │  因子抽象基类：定义标准接口，强制子类实现
├─────────────────┤
│  SMAFactor      │  具体因子：SMA，内部只做 SMA 计算
│  RSIFactor      │  具体因子：RSI，内部只做 RSI 计算
│  ...            │
├─────────────────┤
│  FactorEngine   │  因子引擎：批量注册、并行计算、结果汇总
└─────────────────┘
```

### 代码实现

```python
"""
量化因子框架 —— 高内聚、分层、报错优先

设计要点：
1. 每个因子是一个独立的类，内部完成所有校验与计算。
2. 因子构造函数仅接收自身需要的超参数（如 window）。
3. calculate 方法只接受一个 MarketData 对象，降低耦合。
4. 数据校验由 DataValidator 集中处理，因子内部调用其静态方法。
5. 因子引擎负责调度，不参与具体计算逻辑。
"""

from abc import ABC, abstractmethod
from typing import Dict, List, Union, Optional
import numpy as np


# ============= 数据层 =============

class MarketData:
    """
    统一行情数据容器，持有 OHLCV 等序列。
    所有数据在构造时已完成基本校验，确保不为空且长度一致。
    """
    def __init__(self,
                 open: List[float],
                 high: List[float],
                 low: List[float],
                 close: List[float],
                 volume: List[Union[int, float]]):
        self.open = open
        self.high = high
        self.low = low
        self.close = close
        self.volume = volume

    def __len__(self):
        return len(self.close)


# ============= 校验层 =============

class DataValidator:
    """全局数据校验工具，所有校验方法均为静态，无状态"""

    @staticmethod
    def assert_not_none(value, name: str):
        if value is None:
            raise ValueError(f"{name} 为 None，无法继续")

    @staticmethod
    def assert_positive(value, name: str):
        if not isinstance(value, (int, float)) or value <= 0:
            raise ValueError(f"{name} 必须为正数，当前值 {value}")

    @staticmethod
    def assert_nonnegative_integer(value, name: str):
        if not isinstance(value, (int, float)):
            raise TypeError(f"{name} 类型错误，期望 int/float，实际 {type(value)}")
        if value < 0:
            raise ValueError(f"{name} 不能为负数，当前值 {value}")
        # 检查是否为整数（容忍极小误差）
        if abs(value - round(value)) > 1e-8:
            raise ValueError(f"{name} 应为整数，当前值 {value}")
        return int(round(value))

    @staticmethod
    def assert_length_at_least(data: list, min_len: int, name: str):
        if len(data) < min_len:
            raise ValueError(f"{name} 长度 {len(data)} 小于最小需求 {min_len}")

    @staticmethod
    def validate_market_data(md: MarketData, required_fields: list = None):
        """整体校验 MarketData 对象的必填字段是否存在且长度一致"""
        if required_fields is None:
            required_fields = ['close', 'high', 'low', 'open', 'volume']
        lengths = []
        for field in required_fields:
            arr = getattr(md, field, None)
            DataValidator.assert_not_none(arr, f"MarketData.{field}")
            lengths.append(len(arr))
        if len(set(lengths)) != 1:
            raise ValueError(f"MarketData 各字段长度不一致: {lengths}")


# ============= 因子基类 =============

class FactorBase(ABC):
    """因子抽象基类，强制子类实现 calculate 方法"""
    def __init__(self, name: str):
        self.name = name

    @abstractmethod
    def calculate(self, md: MarketData) -> List[float]:
        """
        计算因子值，返回与 md 长度相同的列表。
        若数据不足或非法，抛出异常。
        """
        pass


# ============= 具体因子：SMA =============

class SMAFactor(FactorBase):
    """
    简单移动平均线因子
    高内聚：所有 SMA 相关的逻辑（校验、计算、边界判断）均在此类中。
    """
    def __init__(self, window: int):
        super().__init__(f"SMA_{window}")
        DataValidator.assert_positive(window, "SMA window")
        self.window = window

    def calculate(self, md: MarketData) -> List[float]:
        # 1. 校验数据完整性（委托给校验层）
        DataValidator.validate_market_data(md, required_fields=['close'])
        close = md.close
        DataValidator.assert_length_at_least(close, self.window, "close")

        # 2. 计算 SMA（纯数学运算，不假设任何默认值）
        result = []
        for i in range(len(close) - self.window + 1):
            segment = close[i:i+self.window]
            # 再次确保段内无 None（理论上不会，但防御性检查）
            if any(v is None for v in segment):
                raise ValueError(f"close 序列中存在 None，位置 {i}-{i+self.window-1}")
            result.append(sum(segment) / self.window)

        # 3. 返回结果长度应与原始数据长度相同（前面补 NaN？不！此处选择报错或补 None？）
        #    根据“报错代替兜底”原则，如果结果长度与原始数据不等，应报错。
        #    但 SMA 本身会缩短序列，通常做法是返回与原始等长的序列（前面填充 None 或 NaN）。
        #    然而“不编造”意味着我们不能凭空填充数值。折衷方案：返回实际计算结果，
        #    并在上层使用时注意长度。这里我们坚持返回实际有效长度，由调用者决定如何处理。
        #    或者我们可以选择在前面填充 None，但 None 也是明确标记，不算编造。
        #    为了符合金融习惯，我们选择在前面填充 None 表示“未定义”。
        #    注意：填充 None 不属于“编造数值”，因为 None 表示缺失。
        padded_result = [None] * (self.window - 1) + result
        return padded_result


# ============= 具体因子：RSI =============

class RSIFactor(FactorBase):
    """
    相对强弱指标因子（Wilder's RSI）
    同样高度内聚，入参仅 window。
    """
    def __init__(self, window: int = 14):
        super().__init__(f"RSI_{window}")
        DataValidator.assert_positive(window, "RSI window")
        self.window = window

    def calculate(self, md: MarketData) -> List[float]:
        DataValidator.validate_market_data(md, required_fields=['close'])
        close = md.close
        DataValidator.assert_length_at_least(close, self.window + 1, "close")  # RSI 至少需要 window+1 个点

        deltas = [close[i] - close[i-1] for i in range(1, len(close))]
        gains = [max(d, 0) for d in deltas]
        losses = [max(-d, 0) for d in deltas]

        # 使用 Wilder 平滑方法
        avg_gain = sum(gains[:self.window]) / self.window
        avg_loss = sum(losses[:self.window]) / self.window

        rsi_values = []
        for i in range(self.window, len(deltas)):
            if avg_loss == 0:
                rsi = 100.0
            else:
                rs = avg_gain / avg_loss
                rsi = 100 - (100 / (1 + rs))
            rsi_values.append(rsi)

            # 更新平滑平均值
            avg_gain = (avg_gain * (self.window - 1) + gains[i]) / self.window
            avg_loss = (avg_loss * (self.window - 1) + losses[i]) / self.window

        # 前面填充 None 使长度与 close 一致
        padded_rsi = [None] * (self.window) + rsi_values  # 第一个 RSI 出现在第 window+1 根K线
        return padded_rsi


# ============= 因子引擎（调度层） =============

class FactorEngine:
    """
    因子引擎：负责注册因子、批量计算、结果汇总。
    不参与任何具体计算逻辑，只做编排。
    """
    def __init__(self):
        self._factors: Dict[str, FactorBase] = {}

    def register(self, factor: FactorBase):
        if factor.name in self._factors:
            raise ValueError(f"因子 {factor.name} 已注册")
        self._factors[factor.name] = factor

    def compute_all(self, md: MarketData) -> Dict[str, List[Optional[float]]]:
        """
        对所有注册的因子依次计算，返回 {因子名: 结果列表}
        任何因子失败都会向上抛出异常，不会跳过。
        """
        results = {}
        for name, factor in self._factors.items():
            results[name] = factor.calculate(md)
        return results


# ============= 使用示例 =============

if __name__ == "__main__":
    # 准备数据
    closes = [100.0, 101.5, 102.3, 103.0, 102.8, 104.2, 105.0]
    market_data = MarketData(
        open=closes,   # 简化，实际应有不同值
        high=[x+0.5 for x in closes],
        low=[x-0.5 for x in closes],
        close=closes,
        volume=[10000]*7
    )

    # 创建因子引擎
    engine = FactorEngine()
    engine.register(SMAFactor(window=3))
    engine.register(RSIFactor(window=5))

    try:
        factors = engine.compute_all(market_data)
        for name, values in factors.items():
            print(f"{name}: {values}")
    except Exception as e:
        print(f"计算终止，原因: {e}")
```

### 设计解读

| 原则 | 实现方式 |
|------|----------|
| **高内聚** | 每个因子类（如 `SMAFactor`）独自承担所有与该因子相关的校验、计算、边界处理，不依赖外部辅助函数（除了通用的 `DataValidator`）。 |
| **入参精简** | 构造函数只接受 `window` 等必要超参数；`calculate` 仅接受 `MarketData` 一个对象，避免传递多个零散列表。 |
| **分层职责** | - **数据层** `MarketData`：统一容器，保证字段完整。<br>- **校验层** `DataValidator`：纯静态方法，专注数据正确性检查。<br>- **因子层** `FactorBase` + 子类：只做因子计算。<br>- **引擎层** `FactorEngine`：只做编排调度。 |
| **报错代替兜底** | 任何数据异常（None、长度不足、非正数）都抛出 `ValueError` 或 `TypeError`，绝不隐式填充或默认处理。 |
| **结果长度一致性** | 对于 SMA、RSI 等会导致序列缩短的因子，采用前面填充 `None` 的方式保持长度一致。`None` 是明确的缺失标记，不属于编造数值。 |

这个设计可以直接嵌入量化回测系统或实盘监控模块，确保每一个因子值的产出都是经过严格校验的。如果您需要扩展更多因子（如 MACD、布林带），只需继承 `FactorBase` 并实现 `calculate` 即可，无需修改其他层。
